# v0.1.7 · 浏览器自动保存

日期：2026-10-13。保持现有页面、AI 解析接口及 CP-SAT 求解流程。

- 在当前浏览器的 `localStorage` 中按场景保存输入文字、任务、资源、约束、确认状态、模式、自定义权重、识别提示、最新求解结果及重新优化需要的上一版安排。
- 页面打开时恢复最后使用的场景及内容，不再无条件加载并求解个人计划例子。即使尚未识别文字或确认草稿，也会保存。
- 场景切换恢复该场景的内容；首次使用的场景仍加载预置方案。“恢复预置方案”仅重置当前场景。
- 保存发生在编辑更新、切换场景、页面隐藏及关闭时；只有模板读取阶段的临时状态不写入。
- 读取时检查存储格式和关键字段，损坏的内容不会造成白屏；写入失败时明确提示，不假装已经保存。
- 保存只属于当前网站地址下的浏览器配置文件；不同电脑、浏览器及无痕会话互不自动同步。清除网站数据会删除本地内容。

保存不包含 API 密钥，不引入登录、同步服务或额外依赖。后端仍对正式求解输入进行模型校验；未确认草稿在刷新后仍须确认。

此功能保存当前工作区，不改变已有服务端求解历史的共享和临时存储边界。

## 验证

TypeScript 检查和 Vite 生产构建通过。`scripts/check_browser_storage.py` 使用真实后端和 Chromium 验证：

- 输入后立即刷新，原文字和求解结果保留，未发起新的求解。
- 新增任务与固定时间约束、自定义权重、上一版安排、未确认状态在刷新后保留。
- 切换场景分别恢复，不重复求解；恢复预置方案只替换当前场景。
- 完全关闭 Chromium 并重开同一磁盘配置文件，恢复最后使用的场景。
- 另一个浏览器配置文件使用独立内容。
- 损坏 JSON 或无效结构能够恢复到预置方案；存储配额错误有明确提示，页面仍能求解。
- 确认恢复的草稿后，请求包含原权重和上一版安排，新增周三 19:00–20:00 会议正确安排；本地结果 `OPTIMAL`，36 项活动，0 条硬约束违反。
- 无页面异常或控制台错误，390px 手机布局没有整体横向溢出。

本地可执行完整检查；部署后使用 `--smoke --url https://atlas-ptbu.onrender.com` 检查同一流程，不重复所有本地故障用例。检查脚本需要 Playwright 和 Chromium，不属于网站运行依赖。
