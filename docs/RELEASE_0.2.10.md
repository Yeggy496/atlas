# OptiDay 0.2.10

- 当用户明确列出两个可用工作时段，而模型为同一目标生成了两个互斥的硬时间窗时，将新生成的那一对转换为可用总时段与中间不可用时段，保留硬约束含义；预先存在的约束不会被重写。
- 提醒用户检查仅覆盖一个时段的活动，以及被模型推断的会议参会人、可能被活动硬时间窗强化的偏好。
- 遇到原文中明确以“希望”表示的工单截止但模型将其误设为硬约束时，仅在可准确匹配工单及时间的情况下，提示该软截止暂未纳入求解；已有约束不会被修改。
- 对 0.2.9 的真实模型输出进行本地重放，会议室和生产排程原来不可行的例子均可求解且通过独立校验。线上模型输出可能变化，仍需部署后重新验证。
