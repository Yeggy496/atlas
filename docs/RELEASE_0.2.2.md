# OptiDay v0.2.2

2026-10-27。在完整 v0.2.1 基线上完成产品改名与界面调整，保留已有业务闭环。

## 这一轮改变

- 产品名称、页面标题、帮助、服务 API 标题、导出文件与 PDF 元数据、配置示例、运行说明统一为 OptiDay。
- 原 Σ 标记替换为自行绘制的时钟／时段 SVG；页面、欢迎界面和浏览器图标使用同一图形。
- 保留白底与现有布局，使用石墨灰正文、深绿操作色和克制的类别色；加深日历文字，取消装饰网格。类别仍由文字和标签区分。
- 兼容旧浏览器工作空间、历史和备份；校验后迁移工作空间，保留旧副本；现有服务器的旧配置前缀继续有效，新前缀优先。兼容代码中的旧标识不是对外产品名称。
- 健康信息区分规则解析与真实模型配置，不把配置凭证等同于模型已经通过在线验收。
- 每次标准构建自动同步两个前端产物，并加强提交检查，防止只上传后端时显示旧界面。

## 对 AI＋软件创新赛题的对应

| 要求 | 当前实现与证据 | 仍需注意 |
| --- | --- | --- |
| 完整核心功能、无重大缺陷 | 统一模型、三主场景、复核、求解、诊断修复、重排、本地保存与备份均经运行检查 | 测试通过覆盖已测边界，不能等同于任意规模、任意输入无缺陷 |
| AI 与业务契合 | 模型输出结构化草稿，经过 Pydantic 和约束校验，再由用户确认；正式结果由 CP-SAT 及独立校验产生 | 规则解析不是大模型；模型理解可能出错，需要用户复核 |
| 易用与方便验证 | 单命令本地运行、已有公网入口、空白开始、主动选择示例、清空／撤销、周／日／清单、可下载和恢复 | 浏览器本地保存不提供跨设备自动同步；免费服务可能休眠 |
| 创新与差异化 | 共用调度核心适配多场景，需求复核、可验证修复和带变更代价的重排形成软件闭环 | 不宣称原创 CP-SAT、不宣称最小冲突核心或保证全局最少改动 |
| 测试与方案可复核 | 后端测试、浏览器流程、真实 API 调用记录、三场景预置对比，见同目录 evidence-20261027 | 新实验不是用户试点；真实试用人数、反馈及效果需由团队实际采集 |
| 合法授权与匿名 | 第三方组件清单、服务端密钥、公开历史默认关闭；本轮包不含私人凭证和数据库 | 最终材料还需检查学校／指导教师信息及第三方引用 |

## 实测

- 标准前端构建通过：TypeScript、Vite、两个生产副本同步。
- 后端 **167 通过、1 跳过**。在线凭证测试默认跳过，不将它计为模型在线成功。
- 原有 **73 组**真实浏览器流程通过；新增 **6 组**品牌、日历对比度和旧数据升级检查通过，均无未捕获页面错误。弱网、额度和模型分段测试中的替身均按脚本说明区分，不视为真实模型准确率测试。
- 三主场景新一轮预置对比：个人 35 项、排课 11 项、实验 6 项，独立校验均为 0 硬约束违反。前两者在 5 秒设置内返回 FEASIBLE，实验返回 OPTIMAL。简单随机、简化贪心只作教学对照，不代表先进算法竞争结果。
- 另对现有公网服务 v0.2.1 完成一次真实 DeepSeek 验收：解析 HTTP 200，用时 3.14 秒，复核门槛有效，CP-SAT 返回 OPTIMAL 且满足指定的周二 14:00。这是一条样例调用，不能推导整体准确率或延迟保证，也不等同于新版本已部署。
- 公网 AI 解释另实测 HTTP 200，2.09 秒，返回 DeepSeek 说明；与不调用模型的解释逐字段比较，确定性事实保持一致。另在本机 Microsoft Edge 验证了首次使用和真实求解；手机部分为 390px 视口测试，不宣称所有实体设备均已验收。

## 交付边界

时间精度 30 分钟；单个活动不跨午夜；最多 100 活动、50 资源、200 显式约束；求解有时限；修复基于有限次单条放宽验证；稳定性是加权目标。优先服务个人、一个班及小型实验团队。

当前更有价值的后续工作是实际用户试用与反馈闭环，再据此修正操作问题。文档、视频、算法说明和测试报告应采用同一版本与真实证据；本轮不扩展账户、更多场景或未经验证的新算法。
